一、五阶闭环研习法则 (Core Methodology)

01
音标与语块感知

利用主谓宾结构着色与 IPA 国际音标标注，建立句子意群断句直觉，从“逐词翻译”跃迁为“词块思维”。

02
盲打槽位拼写

无需使用鼠标，全键盘直接敲击字母，敲击空格自动跳转下一个词槽，Tab 一键呼叫标准母语发音。

03
遮词默写深度沉浸

点击「遮词默写」小眼睛或按快捷键 Ctrl + H 隐藏上方英文，进入看中文直接盲打默写挑战。

04
Whisper 影子跟读

切换至「影子跟读」模式，麦克风录入发音，本地 Whisper 神经模型逐词比对发音契合度，支持 A/B 双轨原声对比。

05
错题攻坚与 SM-2 手账

疑难词块右上角书签一键入生词库，易错题目自动归入「重点攻坚集」，遵循艾宾浩斯遗忘曲线科学复习。

二、极客全键盘快捷键字典 (Keyboard Shortcuts)

快捷按键 功能指令 研习应用场景
Tab 朗读整句标准母语原声 造句工坊 / 听音输入前确认发音节奏
Space 槽位跳格 / 判定当前输入 单词输入完毕后快速跳入下一个词槽
Backspace 删除字母 / 回退前一个槽位 输入错误时光标无缝回跳修改
Ctrl + A 播放当前标准母语音频 研习过程中随时复听句子原声
Ctrl + H 遮词默写 / 显示英文答案 在“默写模式”与“原句对照”间极速切换
Ctrl + M 标记为「已掌握」 句子已熟练掌握，直接通关并跳至下一句
Ctrl + Q 标记为「不熟悉 / 重点攻坚」 将生疏或易错句子收入本章重点攻坚专项集
Esc 返回章节列表 / 关闭弹窗 在任何研习或弹窗界面一键退出

三、自定义教材与网络美文一键切词 (Custom Drills)

在课程库点击右上角的「+ 自定义课文」，直接粘贴任意网络英文新闻、外刊美文、美剧对白或工作邮件。本地部署的大模型将自动进行： 自然断句 ➔ 主谓宾意群切块 ➔ IPA 国际音标标注 ➔ 中文地道对照。 生成完毕后即可永久保存在你的专属课程库中，随时随地开启盲打研习。

四、离线私有与数据存储说明 (Privacy & Architecture)

本地 SQLite 数据库持久化

所有课程学习进度、生词手账、艾宾浩斯复习调度数据完全保存在本地 SQLite 数据库中，绝不上报云端，安全可控。

本地神经 TTS 与 Whisper 评测

发音跟读录音采用本地内存 Blob 双轨缓存比对，语音评测由本地运行的 Whisper 神经引擎驱动，零流量消耗。
