# 静静宝贝专属学习系统 · Jingjing's Exclusive English Learning Lab 🌸

> **专属于静静宝贝的 AI 英语私教 · 闯关自习室（100% 本地运行）**  
> 适配 **Mac mini (16G+256G) 及所有 Apple Silicon Mac**，纯离线/免 API 费用，完全保护隐私。

---

## 🌟 核心功能特色

1. **🧩 宝贝闯关自习室（关卡式积木造句）**
   - 涵盖 **咖啡餐饮、机场交通、朋友闲聊、职场日常、购物生活** 等高频日常交流场景。
   - 英文句子拆解为语法词块，点击放入槽位，即时发音校验与金币/连击奖励。
   - 答对后附带 **语法拆解小课堂 (Breakdown)** 与 **母语者地道文化贴士 (Native Tip)**，并弹出「静静宝贝专属」通关奖励。

2. **🎙️ AI 口语真实场景对练**
   - 涵盖真实生活场景：*Brew & Co. 咖啡馆点餐*、*JFK 机场入境问答*、*周末朋友聚会闲聊*、*硅谷外企茶水间对话*。
   - **零延迟麦克风输入**：直接调用 Mac 原生 Web Speech 引擎，实时上屏转录。
   - **杜绝长篇大论**：严格限制 AI 在 1~3 句日常口语内快速接话，像朋友一样互动。

3. **📋 静静宝贝专属 6 维口语成长档案**
   - 点击“生成成长雷达”，本地大模型会自动生成静静宝贝的专属 6 维档案：
     1. 🌟 **静静今日发音闪光点 (Strengths)**
     2. 💡 **私教地道改写建议 (Native Upgrade)**：中式原句对比地道习语/短语动词
     3. 🎯 **今日专项微练 (Recommended Practice)**：针对薄弱点的小练习
     4. 🌊 **6 维雷达**：流畅度 / 语法准确性 / 词汇广度 / 发音自然度 / 思维发散 / 表达自信
     5. 🗣️ **发音与连读避坑 (Pronunciation & Liaisons)**
     6. 💬 **高阶母语示例回复 (Example Replies)**：母语者怎么说

4. **🔊 超自然口语发音引擎（彻底解决 Edge-TTS 死板问题）**
   - **Kokoro-82M**：当今最自然的轻量离线神经网络发音（仅 300MB，带自然呼吸和起伏）。
   - **Edge-TTS 调优版**：优选 `Ava` 与 `Andrew` 多情感多语种音色，拒绝平板播音腔。
   - **浏览器原生引擎**：极速零等待发音。

5. **📖 静静的闪光生词本**
   - 遇到好的句子或表达，点“收藏”就住进静静的生词本，带来源场景徽章、一键发音和复习勾选。

## 🗄️ 数据存储（SQLite + SM-2 记忆曲线）

所有学习数据保存在本地 SQLite：`data/jingjing.db`（首次启动自动建库，无需手动迁移）。

| 表 | 内容 |
|---|---|
| `profile` | 🌟 能量星、🪙 宝贝金币、🔥 连续天数、最后活跃日 |
| `cards` | 生词本卡片 + SM-2 参数（ease factor / interval / repetitions / lapses / due_at） |
| `reviews` | 每次复习流水（quality 0-5），可用于成长曲线 |
| `diagnostics` | 每次 6 维成长雷达留档，驱动「成长曲线」 |

- **SM-2**：quality ≥ 3 时按 `1 → 6 → interval × ease` 递增，ease factor 下限 1.3。
- **艾宾浩斯兜底**：quality < 3 视为遗忘，回到 `1 / 2 / 4 / 7 / 15 / 30 / 60` 天短阶梯。
- **三档复习**：生词本每张卡片有 `😵 忘了(2)` / `🤔 想起(4)` / `✨ 秒答(5)`，真正驱动调度。
- **旧数据迁移**：首次启动自动把旧版 `localStorage` 的生词本、能量星、金币导入 SQLite，并写入标记 `jj_sqlite_migrated`。
- **自动备份**：每次启动做 `PRAGMA integrity_check` 并把库复制到 `data/backup/jingjing-<日期>.db`，只保留最近 7 份。
- **导出**：`GET /api/notebook/export` 返回完整 JSON（档案 + 卡片 + 诊断历史）。
- **备份/重置**：复制 `data/jingjing.db` 即备份；删除该文件等于清空全部进度。

## 🔒 隐私与本地化

- 服务默认只绑定 `127.0.0.1`（可用 `JJ_HOST` / `JJ_PORT` 覆盖），局域网其他设备无法直连。
- CORS 仅放行本机前端源，不再使用 `*`。
- **前端零 CDN 依赖**：Vue / Tailwind / Phosphor 图标 / 字体全部内置于 `static/vendor/`，断网亦可完整使用。
